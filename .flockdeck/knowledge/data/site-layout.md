| Path | Origin | In image |
|---|---|---|
| `app/*.html` | Generated by docgen ("using Flockdeck" pages) | yes |
| `self-hosting/*.html` | Generated by docgen from `content/self-hosting/*.md` | yes |
| `content/self-hosting/*.md` | Hand-kept Markdown input to docgen | no |
| `index.html`, `docs.css`, `favicon.*`, `apple-touch-icon.png`, `fonts/` | Site shell and assets | yes |
| `nginx.conf` | Server config, moved into `conf.d` during the build | moved, not served |
| `tools/docdrift/` | Drift checks, see [docdrift](/packages/docdrift.md) | no |
| `.docs-generated-from` | [Stamp](/data/docs-generated-from.md) | no |
| `.github/`, `README.md`, `LICENSE`, `Dockerfile`, `go.mod` | Repository only | no |

The build compiles nothing: there is no page discovery step in this repo. `generated.sh regenerate` deletes `app/` and `self-hosting/` and has docgen rewrite them, so a page docgen stops producing disappears. The CI check [asserts](/ci/ci.md) the presence of `index.html`, `docs.css`, `app/getting-started.html` and `self-hosting/overview.html`.

Generated pages must not be hand-edited; see [generated pages gotcha](/gotchas/generated-pages-hand-edit.md). Generation is described in [page generation](/build/regenerate-pages.md).
